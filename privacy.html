隐私政策

最后更新日期：2026年1月1日

⚠️ 核心承诺：FM工具箱的所有工具均在您的浏览器本地运行，您的文件和数据不会上传到任何服务器。这是我们最重要的隐私承诺。

1. 信息收集

1.1 您主动提供的信息

FM工具箱不要求注册，您无需提供任何个人信息即可使用所有工具。当您主动通过 GitHub Issues 或电子邮件联系我们时，我们会收到您自愿提供的联系信息（如邮箱地址），仅用于回复您的咨询。

1.2 自动收集的信息

本网站通过 Google AdSense 展示广告，Google 可能会通过 Cookie 收集以下信息：

  • IP 地址（用于广告地域定向）
  • 浏览器类型和操作系统
  • 访问页面和停留时间
  • 引荐来源网址

这些信息由 Google 自动收集，我们无法直接访问您的个人可识别信息。您可以通过浏览器设置拒绝 Cookie，但可能会影响广告展示。

2. 文件和数据安全

🔒 重要说明：本网站所有工具均基于前端技术（HTML/CSS/JavaScript）实现，所有文件处理均在您的浏览器本地完成。我们没有后端服务器接收您的文件。

具体包括：

  • 文件处理工具（图片处理、PDF预览、文件哈希等）：文件仅在您的浏览器内处理，不会上传到任何服务器
  • 文本处理工具：所有文本均在浏览器本地处理，不会发送到服务器
  • 计算器类工具：计算在数据仅在本地进行

3. Cookie 使用

本网站本身不使用 Cookie存储您的个人信息。但以下第三方服务可能会设置 Cookie：

  • Google AdSense：用于展示个性化广告（如果您同意）
  • Cloudflare：用于网站加速和安全防护（如 cf_clearance Cookie）

您可以通过浏览器设置管理或删除 Cookie。在欧盟地区，您可以通过我们的 Cookie 提示横幅选择是否同意非必要 Cookie。

4. 第三方服务

本网站使用以下第三方服务：

  • Google AdSense：广告展示。Google 的隐私政策：https://policies.google.com/privacy
  • Cloudflare Pages：网站托管和 CDN 加速。Cloudflare 的隐私政策：https://www.cloudflare.com/privacypolicy/
  • GitHub Pages：代码托管（仅用于开源代码，不涉及用户数据）

5. 儿童隐私

本网站不专门针对 13 岁以下儿童设计，也不会故意收集儿童的个人信息。如果您是家长并发现您的孩子向我们提供了个人信息，请联系我们，我们会尽快删除相关信息。

6. 您的权利

根据您所在地区的法律（如 GDPR、CCPA），您可能拥有以下权利：

  • 访问我们持有的关于您的个人信息
  • 要求删除您的个人信息
  • 要求更正不准确的个人信息
  • 拒绝或限制处理您的个人信息
  • 数据携带权（获取您的个人信息的副本）

由于本网站不收集您的个人信息（除联系我们时主动提供外），上述权利在实际使用中很少需要行使。如有需要，请通过 GitHub Issues 或电子邮件联系我们。

7. 本政策的变更

我们可能会不时更新本隐私政策。任何变更都会在此页面上发布，并更新顶部的"最后更新日期"。重大变更时，我们会在首页显著位置通知您。

8. 联系我们
